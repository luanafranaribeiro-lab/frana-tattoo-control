# Frana Tattoo Control

Protótipo mobile-first de uso pessoal para gestão de tattoos, custos, estoque, eventos e orçamentos.

## V1
- Dashboard financeiro
- Registro de tattoos
- Baixa automática de cartuchos
- Consumo de tinta por capacidade do batoque
- Inventário e alertas de estoque mínimo
- Entrada de materiais
- Eventos
- Despesas
- Calculadora de gasolina
- Orçamento básico
- Dados salvos localmente no navegador (localStorage)

## Próximas etapas
- múltiplos cartuchos e tintas por tattoo com editor completo
- kits padrão de insumos
- modo evento rápido e fechamento
- custo fixo/depreciação
- histórico de movimentações
- feedback e calibração de orçamento
- análise de referência por IA
- persistência/sincronização em banco de dados
- PWA instalável
